# Portofolio Marvell

Website portofolio pribadi Marvell Arraya Kusnadi, siswa Rekayasa Perangkat Lunak. Website ini menampilkan profil, riwayat pendidikan, keterampilan, proyek, dan informasi kontak.

## Fitur

- Navigasi ke setiap bagian halaman
- Tampilan responsif untuk desktop dan perangkat seluler
- Efek scroll halus pada navigasi
- Bagian profil, pendidikan, keterampilan, proyek, dan kontak

## Teknologi

- HTML
- CSS
- JavaScript

## Struktur File

```text
.
├── index.html   # Struktur dan konten halaman
├── style.css    # Gaya dan tata letak
├── script.js    # Interaksi navigasi
└── foto.png     # Foto profil
```

## Menjalankan Proyek

Tidak diperlukan instalasi atau build. Buka `index.html` di browser, atau gunakan ekstensi seperti Live Server di Visual Studio Code untuk menjalankan situs melalui server lokal.

## Kustomisasi

- Ubah teks profil dan bagian lainnya di `index.html`.
- Ubah warna, tata letak, dan gaya tampilan di `style.css`.
- Ubah interaksi halaman di `script.js`.
- Ganti `foto.png` dengan foto lain. Jika nama file berubah, perbarui atribut `src` gambar di `index.html`.
